# 商品自動分類システム V2

階層型機械学習による商品分類＋精度検証機能＋特徴量重要度分析を搭載した高度な分類ツールです。

## 機能概要

### 基本機能
- **JAN一致処理**: TRIALマスタとのJANコード完全一致による自動分類
- **階層型ML予測**: カテゴリー→サブカテゴリー→セグメント→サブセグメントの順に予測
- **精度検証**: 複数の学習データ比率で精度を検証し、グラフ表示
- **信頼度判定**: 予測信頼度による3段階分類（高/中/低）
- **フィルター機能**: ステータス・信頼度・検索による結果絞り込み
- **CSV出力**: 分類結果をCSVファイルでダウンロード（UTF-8 BOM付き）

### 新機能（V2）
- **アルゴリズム自動選択**: データ量に応じてLinearSVC/LightGBMを自動選択（500件基準）
- **特徴量重要度可視化**: 4階層別タブで重要な特徴量を横棒グラフ表示（上位20件）
- **SHAP値分析（骨格）**: 個別商品の予測根拠を分析する基盤（将来の拡張用）
- **マルチプロセス対応**: 大量データの高速処理（骨格実装済み）
- **メモリ効率化**: gc.collect()による自動メモリ管理で大量データにも対応

## 使用方法

### Step 1: TRIALマスタファイルアップロード

1. 「TRIALマスタ選択」ボタンをクリック
2. TRIALマスタファイル（CSV/Excel）を選択
3. 必須カラムのマッピング確認:
   - JAN（必須）
   - 商品名（必須）
   - カテゴリー名（必須）
   - サブカテゴリー名（必須）
   - セグメント名（必須）
   - サブセグメント名（必須）

### Step 2: 市場データファイルアップロード

1. 「市場データ選択」ボタンをクリック
2. 分類対象の市場データファイル（CSV/Excel）を選択
3. 必須カラムのマッピング確認:
   - JAN（必須）
   - 商品名（必須）
4. オプションカラム:
   - 規格
   - メーカー
   - 平均価格

### Step 3: 分類処理実行

1. 両ファイルのアップロードが完了したら「分類処理実行」ボタンが表示
2. ボタンをクリックして処理開始
3. 処理中は進捗バーで状態確認

### Step 4: 結果確認

処理完了後、以下の情報が表示されます:

#### 統計情報
- 総件数
- JAN一致件数
- 高信頼度件数
- 中信頼度件数
- 低信頼度件数

#### 精度検証グラフ
- 学習データ比率別の精度推移
- 4階層（カテゴリー/サブカテゴリー/セグメント/サブセグメント）の精度比較

#### 特徴量重要度分析（NEW）
- 4階層別タブで表示
- 各階層で重要な特徴量を横棒グラフで可視化（上位20件）
- どの商品情報が予測に影響しているかを理解できる

#### 結果テーブル
- JAN、商品名、予測結果、信頼度、ステータス、手法の表示
- フィルター・検索機能
- ページネーション（10/25/50/100件表示、全件表示）

### Step 5: 結果ダウンロード

1. 「結果をダウンロード」ボタンをクリック
2. CSVファイル（UTF-8 BOM付き）がダウンロード開始
3. ExcelでもGoogle Sheetsでも文字化けなく開けます

## ステータス説明

### JAN一致（jan_matched）
- TRIALマスタとJANコードが完全一致
- 信頼度: 1.0（100%）
- 最も信頼性の高い分類結果

### 高信頼度（ml_high）
- 機械学習による予測
- 信頼度: 0.7以上（70%以上）
- 高精度で予測された結果

### 中信頼度（ml_medium）
- 機械学習による予測
- 信頼度: 0.4～0.7（40%～70%）
- 一定の精度で予測された結果
- 人手による確認推奨

### 低信頼度（ml_low）
- 機械学習による予測
- 信頼度: 0.4未満（40%未満）
- 予測精度が低い結果
- 人手による確認必須

## トラブルシューティング

### ポート5000がすでに使用されている
他のアプリケーションがポート5000を使用している場合:
```bash
# app.pyの最終行を編集
app.run(debug=True, host='0.0.0.0', port=5001)  # ポート番号を変更
```

### ライブラリインポートエラー
必要なライブラリが不足している場合:
```bash
pip install -r requirements.txt
```

LightGBMのインストールエラーが発生する場合:
- システムにコンパイラがインストールされているか確認
- 事前ビルド済みホイールが利用可能かPyPIで確認
- インストールできない場合でもLinearSVCで動作します

### ファイルアップロードエラー
- ファイルサイズが50MBを超えていないか確認
- ファイル形式がCSVまたはExcel（.xlsx, .xls）か確認
- 必須カラムが存在するか確認

### 精度検証グラフが表示されない
- TRIALマスタに十分なデータ（最低30件以上）があるか確認
- カテゴリー階層が正しく設定されているか確認

## 技術仕様

### 機械学習アルゴリズム（V2）
- **アルゴリズム自動選択**:
  - データ件数 < 500件: LinearSVC（線形サポートベクターマシン）
  - データ件数 ≥ 500件: LightGBM（勾配ブースティング決定木）
- **特徴量**: TF-IDF文字n-gram（商品名＋規格＋メーカー）+ 数値特徴量（容量・価格・入数）
- **階層型学習**: 上位階層の予測結果を次の階層の学習に利用
- **特徴量重要度**: LinearSVCは係数の絶対値、LightGBMは情報利得ベースで計算

### 精度検証方法
- 学習データ比率: 10%, 20%, 30%, 40%, 50%, 60%, 70%, 80%, 90%
- 評価指標: Accuracy（正解率）
- 検証対象: サブセグメント単位での精度評価

### セキュリティ対策
- ファイルサイズ制限: 50MB
- 一時ファイル自動削除
- セキュアなファイル名処理

## ライセンス・免責事項

予測結果は参考情報として利用し、重要な判断には人手による確認を推奨します。
